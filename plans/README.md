## Missed Opportunities (additive, not corrective)

1. **Copy-email feedback** — `src/app/page.tsx:267-269` `Copy email` → `Copied!` teleports text without transition. Add 120ms `transform` + `opacity` crossfade with `filter: blur(2px)` mask to prevent double-exposure (AUDIT §7).
2. **Hero social pills spatial origin** — `src/app/page.tsx:297-302` social icons appear inside hero card with no entrance linking them to the card. Add `transform-origin` or subtle `scale(0.97)+opacity` entrance chained after hero `0.2` delay.
3. **Experience timeline dot reveal** — `src/app/page.tsx:348` rail dot is static. Could animate `scale` from 0.7 → 1 with spring when each `Reveal` enters, for delightful but rare spatial cue.
4. **About illustration → content connection** — `src/components/about-illustration.tsx` dashed lines (`dashMove`) already animate but the laptop screen's code lines could stagger with shared token timing (see plan 004) for tighter cohesion.
